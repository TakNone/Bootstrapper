# updateMessageReactions

**Description** : *New message reactions &raquo; are available*

**Layer** : 233

```tl
updateMessageReactions#1e297bfa flags:# peer:Peer msg_id:int top_msg_id:flags.0?int saved_peer_id:flags.1?Peer reactions:MessageReactions = Update;
```

---

## Parameters

| Name | Type | Description |
| :---: | :---: | :--- |
| <del style = 'opacity : 0.4'>flags</del> | [`#`](type/#) | Flags, see TL conditional fields |

| **top_msg_id** | [`flags.0?int`](type/int) | Forum topic ID |

## Example

```php
$update = $client->updateMessageReactions(
	peer : $client->peerUser(
		user_id : 3294183934629971067,
	),
	msg_id : 13,
	top_msg_id : 2,
	saved_peer_id : $client->peerUser(
		user_id : -139328275641211578,
	),
	reactions : $client->messageReactions(
		min : true,
		can_see_list : true,
		reactions_as_tags : true,
		results : array(
			$client->reactionCount(
				chosen_order : 63,
				reaction : $client->reactionEmpty(),
				count : 93,
			),
		),
		recent_reactions : array(
			$client->messagePeerReaction(
				big : true,
				unread : true,
				my : true,
				peer_id : $client->peerUser(
					user_id : -3119296324958330775,
				),
				date : 32,
				reaction : $client->reactionEmpty(),
			),
		),
		top_reactors : array(
			$client->messageReactor(
				top : true,
				my : true,
				anonymous : true,
				peer_id : $client->peerUser(
					user_id : 6282817051806174761,
				),
				count : 7,
			),
		),
	),
);
```
