**Description** : *Contains the peers that may be used to join a video chat/livestream, see joining on behalf of owned channels &raquo;*

**Layer** : 233

```tl
phone.joinAsPeers#afe5623f peers:Vector<Peer> chats:Vector<Chat> users:Vector<User> = phone.JoinAsPeers;
```

| Name | Type | Description |

| <mark>peers</mark> | [`Vector<Peer>`](type/Peer) | Peers |
| <mark>chats</mark> | [`Vector<Chat>`](type/Chat) | Chats mentioned in the peers vector |
