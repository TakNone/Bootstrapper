# phone.joinGroupCallPresentation

**Description** : *Start screen sharing in a non\-RTMP video chat/livestream or conference\. Presentations are not supported in live stories or RTMP\-mode video chats/livestreams, see here &raquo; for more info*

**Layer** : 229

```tl
phone.joinGroupCallPresentation#cbea6bc4 call:InputGroupCall params:DataJSON = Updates;
```

---

## Parameters

| Name | Type | Description |
| :---: | :---: | :--- |
| <mark>call</mark> | [`InputGroupCall`](type/InputGroupCall) | Joined non-RTMP video chat/livestream or conference in which to start presenting |
| <mark>params</mark> | [`DataJSON`](type/DataJSON) | Join payload generated by a separate local call-engine instance for the presentation |

---

## Result

[Updates](type/Updates)

---

## Possible Errors

| Type | Code | Description |
| :---: | :---: | :--- |
| **GROUPCALL_INVALID** | `400` | The specified group call is invalid |
| **PARTICIPANT_JOIN_MISSING** | `403` | Trying to enable a presentation, when the user hasn't joined the Video Chat with phone.joinGroupCall |

---

## Example

```php
$updates = $client->phone->joinGroupCallPresentation(
	call : $client->inputGroupCall(
		id : -3474954267760425159,
		access_hash : -4835240450644358839,
	),
	params : $client->dataJSON(
		data : 'yFTCkWRSbJxqiHse',
	),
);
```
