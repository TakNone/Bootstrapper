# phone.joinGroupCall

**Description** : *Join any group call type &raquo;\. Conference calls additionally require the E2E joining flow &raquo;*

**Layer** : 233

```tl
phone.joinGroupCall#8fb53057 flags:# muted:flags.0?true video_stopped:flags.2?true call:InputGroupCall join_as:InputPeer invite_hash:flags.1?string public_key:flags.3?int256 block:flags.3?bytes params:DataJSON = Updates;
```

---

## Parameters

| Name | Type | Description |
| :---: | :---: | :--- |
| <del style = 'opacity : 0.4'>flags</del> | [`#`](type/#) | Flags, see TL conditional fields |
| **muted** | [`flags.0?true`](type/true) | Join muted; required for live story listeners and RTMP-mode viewers |
| **video_stopped** | [`flags.2?true`](type/true) | Join with video disabled; required for live story listeners and RTMP-mode viewers |
| <mark>call</mark> | [`InputGroupCall`](type/InputGroupCall) | Group call to join |
| <mark>join_as</mark> | [`InputPeer`](type/InputPeer) | Join the group call, presenting yourself as the specified user/channel; this peer is also used as the author of in-call messages in normal video chats/livestreams. Only video chats/livestreams may use another peer; this field must be equal to inputPeerSelf when joining live stories » or conference calls » |
| **invite_hash** | [`flags.1?string`](type/string) | The invitation hash from the invite link », if provided allows speaking in a livestream or muted group call (video chats/livestreams » only, cannot be used by live stories » or conference calls ») |
| **public_key** | [`flags.3?int256`](type/int256) | For conference calls » only, your public key |
| **block** | [`flags.3?bytes`](type/bytes) | The main-chain block that adds the joining user », only for conference calls » |
| <mark>params</mark> | [`DataJSON`](type/DataJSON) | Join payload generated by the local tgcalls group-call engine, as described above |

---

## Result

[Updates](type/Updates)

---

## Possible Errors

| Type | Code | Description |
| :---: | :---: | :--- |
| **CHAT_ADMIN_REQUIRED** | `400` | You must be an admin in this chat to do this |
| **CHAT_WRITE_FORBIDDEN** | `403` | You can't write in this chat |
| **DATA_JSON_INVALID** | `400` | The provided JSON data is invalid |
| **GROUPCALL_FORBIDDEN** | `403` | The specified group call cannot be used in this context |
| **GROUPCALL_INVALID** | `400` | The specified group call is invalid |
| **GROUPCALL_SSRC_DUPLICATE_MUCH** | `400` | The app needs to retry joining the group call with a new SSRC value |
| **JOIN_AS_PEER_INVALID** | `400` | The specified peer cannot be used to join a group call |
| **PUBLIC_KEY_INVALID** | `400` | The specified e2e public key is invalid |
